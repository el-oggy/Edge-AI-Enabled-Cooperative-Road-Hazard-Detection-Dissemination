# Reference analysis

Inspect the actual video when available. A title, description, caption or search snippet does not establish visual motion. YouTube/Instagram links can require login or fail to play. Use an available browser/media capability; if blocked, say what was inaccessible and request a playable file or a few key frames only when exact matching is required.

Use this compact record in the project brief:

| Aspect | Observation and reusable principle |
|---|---|
| Hook | First meaningful frame, first two seconds, dominant subject |
| Timing | Cuts, holds, ramps, approximate durations |
| Typography | Size hierarchy, tracking, masks, stagger, reading holds |
| Space | Camera, depth, alignment, margins, portrait safe areas |
| Motifs | Shapes, connectors, paper/grids, repeatable relationships |
| Transitions | Match cuts, shape morphs, camera continuity, wipes |
| Audio | Voice anchors, beat sync, risers, impact, silence |
| Adaptation | Which principles suit this product; which specifics are omitted |

Keep observations separate from proposed design decisions. Reference style can guide an original scene without copying its captions, footage, logos or soundtrack. Preserve the product's identity and real claims.

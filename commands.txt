# SUMO Edge-AI Project Commands

### 1. Generate Network from OSM
```powershell
netconvert --osm-files map.osm -o map.net.xml --geometry.remove --roundabouts.guess --ramps.guess --junctions.join --tls.guess-signals --tls.discard-simple --tls.join
```

### 2. List Valid Edges
```powershell
python scripts\list_edges.py
```

### 3. Generate Background Traffic
```powershell
.\scripts\generate_traffic.ps1
```

### 4. Route the Ego Vehicle
```powershell
duarouter -n map.net.xml -r ego_trip.xml -o ego.rou.xml -a vtypes.add.xml --vtype-output dummy.xml --ignore-errors
```

### 5. Download Satellite Imagery
```powershell
python "C:\Program Files (x86)\Eclipse\Sumo\tools\tileGet.py" -n map.net.xml -t 10 -s satellite.xml -m satellite
```

### 6. Run Simulation Visually (GUI)
```powershell
sumo-gui -c map.sumocfg
```

### 7. Run Simulation Headlessly (Data Generation)
```powershell
sumo -c map.sumocfg
```

### 8. Convert Data to Excel
```powershell
python scripts\fcd_to_excel.py
```
